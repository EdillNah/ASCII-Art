1. STRUKTUR & ISI FOLDER CANDLE_FLAME
--------------------------------------------------------------------------------
Folder ini memuat seluruh berkas proyek simulasi lilin ASCII:

- candle.py
  Program utama visualizer berbasis Python, NumPy, dan Pygame-CE.
  Mengimplementasikan shader prosedural ASCII untuk pergerakan roh api,
  lelehan lilin, gelombang lingkaran, pendaran cahaya, serta penanganan input.

- requirements.txt
  Daftar pustaka pihak ketiga yang dibutuhkan (numpy dan pygame-ce).

- README.md
  Dokumentasi visual lengkap untuk repositori Git, mencakup alur fase
  animasi dalam bentuk grafis vektor (SVG), penjelasan teknis sistem,
  dan kontak kreator.

- README.txt
  Dokumentasi cepat dalam format teks biasa untuk panduan offline.

- LICENSE.txt
  Ketentuan lisensi dan hak cipta proyek.

- images/
  Direktori penyimpanan aset dokumentasi (berkas grafis alur simulasi
  01_pitch_black_approaching.svg hingga 04_full_scene_burning.svg)
  serta wadah penyimpanan otomatis hasil tangkapan layar (screenshot).

--------------------------------------------------------------------------------
2. PANDUAN MENJALANKAN PROGRAM
--------------------------------------------------------------------------------
1. Buka terminal atau konsol di direktori candle_flame.
2. Pasang pustaka pendukung:
       pip install -r requirements.txt
3. Jalankan aplikasi:
       python candle.py

--------------------------------------------------------------------------------
3. KONTROL INTERAKTIF
--------------------------------------------------------------------------------
[SPASI] : Menjeda (pause) atau melanjutkan animasi. Layar akan menampilkan
          status [PAUSED] saat jeda aktif.
[R]     : Mengulang (restart) simulasi dari awal (t = 0.00s).
[S]     : Mengambil tangkapan layar (screenshot) beresolusi penuh.
          Berkas otomatis tersimpan ke folder images/ dan folder proyek.
[ESC]   : Menutup aplikasi.
